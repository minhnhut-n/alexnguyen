BP4M4 ST7735 Monitor
====================

Project điều khiển màn hình ST7735 (giao tiếp SPI) trên board BP4M4 — từ
hardware pinout, giao thức lệnh hiển thị, cho đến tầng tối ưu phần mềm
(Frame Buffer, SPI DMA).
